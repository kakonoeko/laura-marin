# Laura Marín · zovemselaura

Web adaptable a móvil, en español, serbocroata (alfabeto latino) e inglés. HTML, CSS y JavaScript sin compilación. Preparada para GitHub Pages, con rutas relativas compatibles con `/laura-marin/`.

## Publicación

En Settings → Pages, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda. URL prevista: https://kakonoeko.github.io/laura-marin/

## Contenido y mantenimiento

- `index.html`: estructura, imágenes, enlaces y actuaciones.
- `style.css`: diseño y adaptación a móvil.
- `app.js`: las tres traducciones, idioma persistente, vídeos y contacto Gmail.
- `SOURCES.md`: investigación y procedencia del contenido.

El formulario abre Gmail con destinatario, asunto y propuesta codificados; la persona debe revisar y enviar desde Gmail. No envía correos automáticamente ni recoge datos en un servidor. Incluye enlace alternativo `mailto:`. Los vídeos de YouTube se cargan después de pulsar reproducir; incluyen enlace alternativo si la inserción está restringida. Instagram y TikTok se enlazan directamente.

Noticias seleccionadas a 12 de octubre de 2026. No existe actualización automática de la agenda. Las actuaciones incluidas son pasadas; no se anuncian fechas futuras ni disponibilidad garantizada.

Las fotografías proceden de artículos públicos y se enlazan desde su alojamiento original, con créditos visibles. Su disponibilidad depende de esos medios. Antes de presentar esta propuesta como web oficial, conviene que Laura confirme el texto y facilite fotografías de prensa autorizadas para alojar permanentemente. No se ha aplicado una licencia abierta a las fotografías ni a la música.

El selector SH corresponde al serbocroata en alfabeto latino y utiliza vocabulario ampliamente comprensible en Bosnia, Croacia y Serbia. La revisión editorial por la artista permite ajustar su preferencia regional.

## Comprobación local

Sirve esta carpeta con cualquier servidor HTTP estático. No requiere claves, dependencias ni instalación. Se puede compartir cada versión usando `?lang=es`, `?lang=sh` o `?lang=en`.
